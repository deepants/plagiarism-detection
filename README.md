# AI Content Detector - Flask Application

A modern web application that analyzes text to detect if it was generated by AI, powered by Google's Gemini 2.5 Flash API.

## Features

- 🎯 Accurate AI content detection with percentage score
- 🎨 Modern, responsive UI with gradient design
- 📊 Visual percentage display with animated circular progress
- 🔍 Detailed analysis with reasoning and indicators
- 🔒 Secure API key storage on server side
- ⚡ Real-time character counter
- 📱 Mobile-friendly responsive design

## Setup Instructions

### 1. Install Python Dependencies

```bash
pip install -r requirements.txt
```

### 2. Add Your Gemini API Key

- Open `app.py`
- Find line 8: `GEMINI_API_KEY = 'YOUR_API_KEY_HERE'`
- Replace with your actual API key from [Google AI Studio](https://aistudio.google.com/app/apikey)

### 3. Run the Application

```bash
python app.py
```

The application will start at `http://127.0.0.1:5000`

### 4. Use the Application

- Open your browser and go to `http://127.0.0.1:5000`
- Paste or type text (minimum 50 characters)
- Click "Analyze Text"
- View the results with percentage and detailed analysis

## How It Works

The application uses Google's Gemini 2.5 Flash model to analyze text patterns and characteristics that indicate whether content was AI-generated or human-written. The Flask backend securely handles API calls, keeping your API key safe.

## Results Interpretation

- **0-29%**: Likely Human-Written (Green)
- **30-69%**: Mixed or Uncertain (Orange)
- **70-100%**: Likely AI-Generated (Red)
